JavaScript Objects: Copy by Reference

In this example, aa and bb point to the same object. Assigning an object variable to another variable does not make a separate copy of the object.

The code

let aa = { status: 'pass' };
let bb = aa;              // bb refers to the same object as aa
bb.status = "fail";       // updates that shared object

console.log(aa.status);  // "fail"

Memory picture

Think of aa and bb as two labels pointing to one box:

aa
points to →
{ status: "fail" }
bb
also points to →
same object

Step by step

  1. aa is set to an object whose status is "pass".
  2. bb = aa makes bb refer to that same object.
  3. bb.status = "fail" changes the shared object's property.
  4. Reading aa.status sees the updated value: "fail".

Want an independent object?

For this one-level object, spread syntax creates a shallow copy: 

let aa = { status: 'pass' };
let bb = { ...aa };
bb.status = "fail";

console.log(aa.status); // "pass"
console.log(bb.status); // "fail"

A shallow copy separates the top-level object, but nested objects are still shared. For the original code, the key idea is: both variables refer to one object, so a property change through either name is visible through the other.
