## Core Principles

1. **Important Rule** : Make sure that you have asked the user about the product requirement documents and do not assume. Only create the information, only create a test plan by using a template and use the knowledge which is given in the product requirement document.
2. **Follow best practices** -- Make sure that you follow the best practise, create a test plan properly, well organised, which can be production ready and can be shared with my qa lead automatically.
